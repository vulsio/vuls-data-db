The Extensions repository

The Extensions repository will contain hand-picked upstream content that has gone through Red Hat’s Secure Supply Chain to ensure trust in its chain of custody.

These packages will be “Known by Default”, meaning they will be consumable and manageable within the RHEL ecosystem, including Satellite, Insights and Image Builder. This repository, disabled by default, will contain only the latest software versions and is not tied to the RHEL release cadence, meaning new packages can be released at any time.

Red Hat supports customers using Red Hat Validated content with Red Hat platforms according to the Red Hat Third Party Component Policy. This means that there are no long-term lifecycle and/or ABI commitments for the extensions repository and Red Hat will ask the customer to reproduce the issue using a Red Hat certified or partner validated product. For further help on the issue, the customer will be directed to the third party.

For more information, see the Red Hat Extensions Repository Support Policy.
